# CronCreate 表达式参考

## 基础语法

```
分钟 小时 日 月 星期
 0   12  *  *   1    → 每周一 12:00
```

| 字段 | 范围 | 特殊值 |
|------|------|--------|
| 分钟 | 0-59 | */5 = 每5分钟 |
| 小时 | 0-23 | |
| 日 | 1-31 | |
| 月 | 1-12 | |
| 星期 | 0-7 (0=周日) | 1-5 = 工作日 |

## 推广常用表达式

| 场景 | Cron | 说明 |
|------|------|------|
| 周一 12:30 发布 | `28 12 * * 1` | 提前2分钟提醒粘贴 |
| 周三 20:00 发布 | `58 19 * * 3` | 提前2分钟提醒 |
| 周五 21:00 发布 | `58 20 * * 5` | 提前2分钟提醒 |
| 周六 10:00 发布 | `58 9 * * 6` | 周末上午 |
| 每天发布前一天检查 | `7 20 * * *` | 每晚8点检查 |
| 每周一早上排期 | `7 9 * * 1` | 周一规划 |
| 每周日晚复盘 | `7 21 * * 0` | 周日总结 |
| 发布后24h数据检查 | 手动设置，发布日+1 | |

## 发稿窗口

### 小红书最佳时间
- 工作日晚：20:00-22:00 → `随机分钟 19-21 * * 1-5`
- 午休：12:00-13:00 → `随机分钟 11-12 * * 1-5`
- 周末：10:00-11:00, 21:00-22:00

### 小黑盒最佳时间
- 每晚：19:00-23:00 → `随机分钟 19-22 * * *`
- 周末全天

## 提醒类型

| 类型 | 提前量 | 用途 |
|------|--------|------|
| 准备提醒 | 前一天 | "明天要发小红书，文案配图检查" |
| 发布提醒 | 2-10分钟 | "打开App准备粘贴发布" |
| 数据复盘 | 24小时后 | "检查数据，记录互动" |
| 周度复盘 | 周日 | "本周推广数据汇总" |

## 注意事项

- 不要用分钟 0 或 30（全球用户撞车）
- 使用 `CronCreate` 工具（Claude Code 原生支持，无需额外 skill）
- 一次性任务用 `recurring: false`
- 周度复盘用 `recurring: true`（自动续7天）
