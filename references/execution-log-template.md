# 执行记录模板

复盘提醒触发后，打开对应文件填入以下内容。

## 文件命名

```
execution-log/[project]/[YYYY-MM-DD]-[平台].md
```

## 模板

```markdown
# [平台] 发布复盘 — [日期]

## 基本信息
- 标题 Hook：[文案标题]
- 发布时间：[时间]
- 文案文件：[路径]

## 数据
| 指标 | 数值 |
|------|------|
| 阅读/曝光 | |
| 点赞 | |
| 收藏 | |
| 评论 | |
| 分享 | |
| 粉丝转化 | |

## 评论精选
> [有代表性的评论，正面负面都记]

## 自我评估
- 做得好的：[1-2点]
- 可改进的：[1-2点]
- 意外发现：[如果有]

## 下一步
- [ ] 做变体（如果数据 > 预期 50%）
- [ ] 调整发布时间
- [ ] 换个 Hook 角度重试
- [ ] 放弃这个角度
```
